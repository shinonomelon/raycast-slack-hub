# 履歴・スレッド・リアクション

実APIでの検証が終わるまでは、各画面で検証待ちの案内が出ます。以下は有効化後の操作です。
Actionsを開くキーはRaycast側の設定を使います。拡張側でOSやRaycastのキー設定を変えません。

## 操作

| やりたいこと             | フロー                                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| メッセージの背景を読む   | メッセージを選ぶ → View Surrounding Messages → Load More。前後10分のチャンネル投稿を読み、Earlier/Laterで範囲を広げる |
| スレッドを読む           | メッセージを選ぶ → View Thread → Load More。返信はReply in Threadで既存フォームを開く                                 |
| リアクションを付ける     | メッセージを選ぶ → Add Reaction → 標準絵文字を選ぶ                                                                    |
| 自分のリアクションを外す | メッセージを選ぶ → Remove My Reaction → 自分が付けた絵文字を選ぶ                                                      |

閲覧用の一覧はReturnで対象を開き、⌘Returnで詳細を表示・非表示にします。
候補選択のReturnは選択確定、フォームの⌘Returnは送信です。戻ると親画面の検索・絞り込みを保ちます。

## 検索・取得の範囲

履歴はチャンネル投稿です。スレッド内の返信が履歴にない場合も、選択元の検索プレビューを残し、View Threadで返信本文を取得します。履歴0件をメッセージの削除と判定しません。

Load Moreは1ページずつ読みます。読み込み途中の履歴を「選択直後の全投稿」とは表示しません。

## 追加するUser Token Scopes

| 機能                             | 追加scope          |
| -------------------------------- | ------------------ |
| 公開チャンネルの履歴・スレッド   | `channels:history` |
| 非公開チャンネルの履歴・スレッド | `groups:history`   |
| DMの履歴・スレッド               | `im:history`       |
| グループDMの履歴・スレッド       | `mpim:history`     |
| 自分のリアクションの取得         | `reactions:read`   |
| リアクションの追加・除去         | `reactions:write`  |

今回使う機能に必要なものだけを追加します。現在、`bookmarks:read`・`bookmarks:write`・`lists:read`・`lists:write`は不要です。
scopeをアプリ設定に追加しただけでは、既存のトークンへ付与されません。ワークスペースへ再インストールして承認し、必要ならRaycastのトークンを更新してHubを開き直します。

履歴の回数制限はSlackアプリの配布条件で異なります。Raycast Storeへの公開はSlack Marketplaceへの公開とは別です。429では案内された待機時間を守り、取得済みの結果から確認を続けられます。

## 書き込みの結果を確認する

「変更結果は未確認です」と出た場合はSlackで確認してください。自動では再送しません。保存に成功した後の一覧取得が失敗した場合も、保存自体の失敗とは扱いません。
リアクションは、Hubの「対応済み」の印を変更しません。

## ブックマークとListsは後回し

ブックマークの閲覧・追加・編集・削除と、Listsの検索・項目閲覧・タスク操作は今回の対象から外しています。View Bookmarks・Browse Lists・Create Task from Messageの入口は表示しません。
これらの対応は必要な検証がそろった後に再開します。現在、ブックマークとLists用の権限を追加する必要はありません。
Listsと個人用To-dosは別機能です。
