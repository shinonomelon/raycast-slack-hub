# 返信待ちを確認する

[READMEへ戻る](../README.md)

Slack Hubの表示切替から「返信待ち」を開き、過去24時間または7日間の依頼を確認します。対象は他人から届いた1対1 DMと、自分への直接メンションです。グループDMは直接メンションのある投稿だけを対象にします。

## 基本の使い方

1. Slack Hubを開く → 画面右上の表示切替 → 「返信待ち」を選ぶ。
2. 対象期間を「過去24時間」または「過去7日」に切り替える。
3. 候補を選ぶ → ReturnでSlackを開く。⌘Returnで本文と確認状態の詳細を表示する。
4. 返信する場合はActionsから返信フォームを開く。Slackを開いただけでは候補は消えない。
5. 返信が必要なければ「返信不要」を選ぶ。「あとで対応」は1時間後または翌朝9時まで延期する。
6. 「除外・あとで対応」で一覧を確認し、取り消せる。新しい依頼が届けば、以前に除外したスレッドでも再表示される。

取得結果は5分間キャッシュします。期間内に開き直すと再取得せず表示し、「続きを確認」で保存した位置から残りの履歴を取得できます。過去24時間と7日の結果は別々に保存します。⌘Rはキャッシュを使わず取り直します。

## どこまで確認できるか

同じスレッドや通常DMに、対象投稿より後の自分の投稿があるかを確認します。これはその依頼が解決した証拠ではありません。別の会話で返答した場合や、リアクションで了承した場合は本人が「返信不要」にできます。

未読だけに絞らないため、読んでから返信を忘れた投稿も確認できます。他人が返信しただけでは候補を消しません。

検索結果にはSlack側のフィルターや取得上限の影響があります。表示する順位は取得した候補の中での順位です。履歴が不足するものは「確認待ち」に残ります。権限不足、回数制限、時間切れは詳細で確認してください。

## AIで並べる

AIは任意機能で、初期状態は無効です。候補の閲覧にはTypeSafeのキーは不要です。

1. Raycastの設定 → Extensions → Slack Hub → `TypeSafe API Key (Optional)`へ、自分のTypeSafe APIキーを入力する。
2. Slack Hubを開き直す → 「返信待ち」 → 「AIで並べる」を選ぶ。
3. 送信先と送信内容を確認して有効にする。キーを設定しただけでは送信しない。
4. 判定が終わったら「AI判定を反映」を選ぶ。操作途中に一覧が並び替わることを防ぐため、反映を分けている。

Jevで返信の必要性、期限の切迫、返答待ちによる業務停止、再催促を判定します。判定理由は固定の説明文と元投稿で確認できます。文章生成や自動返信は行いません。

判定後は「要確認」「優先候補」「返信不要の可能性」に分かれます。AIが返信不要と判断しても候補は残ります。表示切替で「優先候補のみ」を選べます。曖昧な期限や不足した文脈は要確認に残ります。

AIには取得した会話本文・投稿時刻・タイムゾーン・相対的な投稿者情報を送ります。送信先はTypeSafeです。Slackのトークンやプロフィール項目は送りません。本文に含まれる名前やメールアドレスなどは自動では除去しません。1回の判定は最大20候補、1候補の文脈は最大30投稿・16,000文字です。ファイルやリンク先の本文は取得しません。

TypeSafeの利用料金は各利用者のアカウントに発生します。Claude Codeのサブスクはこの機能には使いません。AIを無効にすると以降の送信を停止しますが、既に送った内容は取り消せません。

AI連携は開発中です。日本語の判定精度と実画面の検証が終わるまで、実用精度を保証する説明は付けません。

## 必要なSlack権限

候補検索は既存の`search:read`を使います。返信履歴の取得には対象の会話に応じて、User Token Scopesへ次の権限を追加してください。

| 対象                       | 権限               |
| -------------------------- | ------------------ |
| 1対1 DM                    | `im:history`       |
| 公開チャンネル             | `channels:history` |
| 非公開チャンネル           | `groups:history`   |
| グループDMの直接メンション | `mpim:history`     |

追加後はSlackアプリを再インストールし、トークンが変わった場合はRaycastのSlack Access Tokenを更新してSlack Hubを開き直します。追加権限がない会話は確認待ちになり、既存の検索・投稿は使えます。

## 保存するもの

取得した本文・返信の確認結果・取得途中の位置・AI判定を、Raycastのローカルキャッシュへ保存します。再利用する期限は5分です。キャッシュを保存し直しても期限は延長しません。期限切れの結果は読み込み時に削除します。

ワークスペースと本人ごとに保存先を分け、トークンやAIキーの変更を検出した場合は以前の取得結果とAI判定を削除します。生のトークンとAPIキーはキャッシュへ保存しません。

反映済みのAI判定は、入力内容が変わらず期限内なら開き直しても表示します。送信の同意は保存せず、開き直しただけではAIへ送信しません。

返信不要・延期の印とAPIの再開可能時刻も保存します。印は14日で期限切れになり、取得結果を更新しても保持します。

既存の「自分宛て」の開いた・対応済み印とは独立しています。AIキーはRaycastのpassword設定に保存します。
