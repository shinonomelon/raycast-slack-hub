# Slack Hubの詳しい使い方

[READMEへ戻る](../README.md)

検索の条件、ショートカット、自分宛ての整理を確認したいときに読むページです。

## 使い方とキー

Raycast で `Slack Hub` を開きます。

一覧のReturnは選択した対象をSlackで開き、⌘Returnは詳細を表示・非表示にします。メッセージも会話・人も同じ操作です。会話・人と所属一覧の通常参加者へのWriteは⌘Nです。フォーム内の⌘Returnは引き続き投稿操作です。

- 名前を打つと、会話（チャンネル・非公開チャンネル・グループ DM）と人が並びます。お気に入りと、未読のある会話が上に来ます。未読の数は、行の右側に赤いタグで出ます。`3+` の `+` は、実際はそれ以上あるという印です。
- 名前と `in:`・`from:`・`to:` の候補は、ファジー検索に対応します。`prj`で`project_alpha`、`project_alpa`や`project_alhpa`でも`project_alpha` を探せます。別名と辞書の検索語にも効きます。既存の完全一致・前方一致・部分一致を上位に保ち、その後に英数字の誤字、飛び飛び一致を並べます。
- 飛び飛び入力は3文字以上で、文字の順序を守り、一致区間が入力長の2倍以下の場合に当たります。誤字補正は4文字以上の英数字語に限り、語全体または名前の区切りごとの語に、1文字の挿入・削除・置換か隣接2文字の入れ替えを許容します。日本語の誤字・読み仮名変換は扱いません。スペース区切りの複数語はすべて一致する候補だけを出します。
- 絞り込みのファジー候補は、選んでUse This Candidateを実行すると正式な語になります。入力ミスのある宛先を自動で確定しません。メッセージ本文の検索は、従来どおりSlackの検索を使います。
- 語や `in:`・`from:`・`to:` を打つと、会話の下に、メッセージの検索結果が新しい順に並びます。1回に100件までなので、古いものは語や日付で絞ります。
- 何も打たずに開くと、先頭に「自分宛て（過去7日）」が出ます。対象は、自分へのメンションと、自分宛ての DM・グループ DM です（自分の投稿は除きます）。そのうち未読のものを並べます。スレッドの返信と、既読かどうか分からないものも、見落とさないように並べます。`@here`・`@channel`・ユーザーグループ宛ては含みません。

検索欄では、次の書き方が使えます。

| 書き方                                                        | 意味                                         |
| ------------------------------------------------------------- | -------------------------------------------- |
| `in:#チャンネル名`                                            | そのチャンネル。`in:@名前` は、その人との DM |
| `from:@ハンドル`                                              | その人の投稿                                 |
| `to:@ハンドル`                                                | その人宛て                                   |
| `from:me`・`to:me`                                            | 自分の投稿、自分宛て                         |
| `-from:@ハンドル`                                             | 頭に `-` を付けると、除外                    |
| `after:`・`before:`・`on:`・`during:`・`has:`・`is:`・`with:` | Slack の検索の書き方のまま渡します           |

`in:`などを打っている間は候補が先頭に出ます。Use This Candidateで確定します。

画面下部のActionsをクリックすると、選んだ行の操作一覧が開きます。キーで開く場合はRaycast側の設定を使います。

### 参加している人からチャンネルを探す

- **ある人がいるチャンネルを探す**：Slack Hubで人名を検索 → 人のActionsでView Channels with This Person → チャンネル名や別名で絞り込む → Open in Slack。対象は公開チャンネルと、自分も参加する非公開チャンネルです。アーカイブは除きます。投稿履歴を調べるfrom:とは別の検索です。
- **複数人がいる場所を探す**：参加チャンネル画面 → Add Person → 人を選ぶ → 選んだ全員が参加するチャンネルだけを表示。最大5人で、「自分」も選べます。Remove Personで1人を外し、Reset Peopleで最初の人へ戻します。
- **チャンネルの参加者を探す**：チャンネル行のActionsでView Members → 名前・ハンドルで絞り込む → Open in Slack、Write、View Channels with This Person。ボットは「ボット」、名前を取得できないIDは「状態未確認」と表示し、この2種類にはDM・参加チャンネル操作を出しません。
- **メッセージから探す**：メッセージのActionsでView Channels with Sender、またはView Channel Members。送信者を特定できない場合やDM・グループDMでは、該当する操作を出しません。
- **見つけたチャンネルで書く・検索する**：参加チャンネル画面のWriteで投稿フォーム、Search in This Conversationで専用のメッセージ検索画面を開きます。返信フォームも開けます。戻ると元のSlack Hubの検索語と選択行が残ります。
- **参加状況を取り直す**：Refresh。取得時刻を表示し、2分以内の完全な結果は再利用します。Refreshではキャッシュを使いません。同じ条件の更新中・失敗時に以前の結果を残す場合は「前回取得」と表示します。失敗は参加者ゼロとして扱いません。回数制限では表示した秒数を待ってから再試行してください。

一覧の名前入力は取得済みデータを絞り込み、ファジー検索に対応します。空の一覧でもActionsから参加条件の変更とRefreshを実行できます。認証設定を変更した場合はSlack Hubを開き直してください。

### 会話・人の操作

| Actionsの操作名                                     | できること                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------------ |
| Open in Slack                                       | Slackで開く                                                              |
| Show Details / Hide Details                         | 取得済みの名前・種別・ハンドル・別名などを表示・非表示。追加取得はしない |
| Write                                               | 投稿フォームを開く。人の行はDM                                           |
| Filter by This Conversation / Filter by This Person | 会話・人で絞り込む                                                       |
| Add to Favorites / Remove from Favorites            | お気に入りに入れる・外す                                                 |
| Edit Aliases                                        | 別名を付ける                                                             |
| Edit Dictionary                                     | 名前の置き換え辞書を編集する                                             |
| Copy ID                                             | IDをコピーする                                                           |
| Reset Ranking                                       | その行の利用頻度による並び順をリセットする                               |

### メッセージの操作

| Actionsの操作名                                | できること                                                           |
| ---------------------------------------------- | -------------------------------------------------------------------- |
| Show Details / Hide Details                    | 全文をサイドバーに出す・閉じる。読むだけなら「開いた」の印は付かない |
| Open in Slack                                  | 投稿の位置をSlackで開く                                              |
| Reply in Thread                                | スレッドに返信する                                                   |
| Mark as Handled / Unmark as Handled            | 「対応済み」の印を付ける・外す                                       |
| Filter by This Conversation / Filter by Sender | 会話・送信者で絞り込む                                               |
| Open Permalink in Browser                      | メッセージのリンクをブラウザで開く                                   |
| Copy Permalink                                 | メッセージのリンクをコピーする                                       |

「開いた」「対応済み」の印が付いた行は、Slack Hub を開き直すと、自分宛ての一覧から外れます。印は14日で消えます。返信を送れたときも、その行に「開いた」の印が付きます。

自分宛ての保存結果では、長い本文は先頭300文字のプレビューです。Reload Search（⌘R）で取り直すと全文を表示します。通常のメッセージ検索では全文を表示します。

### 再読み込み・並び替え・投稿

- Swap Conversations and Messages：会話とメッセージの並びを入れ替える。
- Reload Search：検索、自分宛て、既読位置、お気に入りの未読を取り直す。
- Reload Conversations and People：会話と人の一覧をすべて取り直す。バックグラウンドで5分ごとに確認し、会話・参加状況は1時間、人は1日経過したものを更新する。
- 参加状況の切り替え：検索欄の右のドロップダウンで、すべて・参加中・未参加を選ぶ。
- Post and Open in Slack：フォームから投稿してSlackで開く。
- Preview：投稿前の本文を見る。

### Slack Hubが定義するショートカット

以下は拡張のコードで定義しているキーです。Actionsからも同じ操作を選べます。Raycastが割り当てる標準キーは、画面の表示を確認してください。

| キー      | 操作                               |
| --------- | ---------------------------------- |
| Return    | 一覧で選択した対象をSlackで開く    |
| ⌘Return   | 一覧の詳細を表示・非表示           |
| ⌘N        | 会話・人へのWriteフォームを開く    |
| Tab / ⌘F  | 会話・人で絞り込む                 |
| Shift+Tab | 会話とメッセージの並びを入れ替える |
| ⌘⇧R       | 会話と人の一覧を取り直す           |
| ⌘⇧D       | 対応済みの印を付け外しする         |
| ⌘⇧Return  | スレッドに返信する                 |
| ⌘D        | 名前の置き換え辞書を編集する       |
| ⌘⇧P       | 投稿のプレビューを見る             |
| Control+X | 辞書の規則を削除する               |

本文は Markdown で書けます。メンションは、本文とは別の欄で選びます。投稿は、あなた自身の投稿として Slack に出ます（ボットの投稿ではありません）。

## 未対応の機能

下書き、メッセージ前後の履歴・スレッド閲覧、リアクション、ブックマーク、Lists、返信待ち・AI判定は使えません。対応状況と再開時の条件は[対応予定](roadmap.md)にまとめています。

検索結果の全文表示、投稿・スレッド返信、自分宛ての対応済み操作は引き続き使えます。
